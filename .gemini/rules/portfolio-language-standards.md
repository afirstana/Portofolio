# Portfolio Content Language Invariant

## 1. 100% Professional English Mandate
- All portfolio content, markdown case studies, interactive UI components, chart labels, metadata (OpenGraph/SEO), tooltips, and system architecture blueprints MUST be written in fluent, professional, high-impact English.
- Avoid informal phrasing, untranslated terms, or placeholder jargon. Ensure technical and business terminology is accurate (e.g., GMV, AOV, installment elasticity, fulfillment lead times).
