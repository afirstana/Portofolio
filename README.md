# Abimael — Senior Data Analytics & Engineering Portfolio

Portfolio personal data analytics, financial intelligence, dan machine learning engineering berbasis **Next.js 15 App Router**, **TypeScript**, **Tailwind CSS**, dan **Local-First Markdown**.

Dibangun secara murni tanpa ketergantungan runtime backend, database server, maupun layanan berbayar. Seluruh komputasi visual (termasuk kanvas 3D manifold, graf jaringan kejahatan finansial, simulasi inferensi NLP, dan kalkulasi risiko) dieksekusi 100% di browser pengguna (*client-side*).

---

## 🚀 Proyek Unggulan

1. **Banking Transaction Anti-Fraud Suite**: 6 Dasbor Forensik Power BI & Deteksi Anomali Berbasis SQL Window Functions.
2. **Brent Oil 3D Volatility Manifold**: Topologi permukaan 3D volatilitas harga minyak bumi (1987–2022) dengan 7 suar krisis global.
3. **Banking Fraud 3D Network Intelligence**: Graf jaringan terarah fisika 3D Coulomb-Hooke melacak 495 entitas perbankan dan 3 sindikat kejahatan.
4. **Global Cancer Epidemiology Surveillance**: Analisis beban kanker global 185 negara dengan rasio mortalitas dan elastisitas GDP.
5. **Banking Fraud 3D Anomaly Manifold**: Ruang fitur laten $\mathbb{R}^3$ dengan bidang hiper-keputusan $\mathcal{H}(\tau)$ dan matriks konfusi real-time.
6. **Olist E-Commerce Logistics & Customer Intelligence**: Pemodelan geodesik Haversine dan segmentasi RFM 9-tier pada 99.441 pesanan Brasil.
7. **Olist Payment & Installment Behavior Analytics**: Analisis ekosistem pembayaran kartu kredit dan anomali lonjakan cicilan 10x.
8. **Brent Oil Market Dynamics**: Ekonometrika deret waktu 35,5 tahun, distribusi leptokurtik (*kurtosis 45,43*), dan kalkulasi VaR/ES 99%.
9. **Amazon Product Review Intelligence**: Mesin inferensi sentimen NLP statis yang berjalan di browser tanpa server GPU.
10. **ML Product Taxonomy Mapping System**: Ansambel 6-model hierarkis dengan active learning sub-milidetik untuk standardisasi SKU manufaktur.
11. **Revenue Reconciliation Automation**: Pipa otomatisasi rekonsiliasi faktur pajak 4-tier dengan verifikasi audit dua arah.
12. **Certificate Generator Desktop Application**: Mesin kalibrasi tipografi vektor otomatis dengan tanda tangan hash kriptografis SHA-256.

## 🛠️ Menjalankan di Lingkungan Lokal

```bash
# Instalasi dependensi
npm install

# Menjalankan server pengembangan
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada peramban Anda.

---

## 🏗️ Build Produksi & Static Export

```bash
npm run build
```

Perintah di atas menjalankan pemeriksaan tipe, prebuild manifest, kompilasi Next.js static export ke direktori `out/`, dan pengemasan sumber statis.
